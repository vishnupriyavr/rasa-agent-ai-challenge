# rasa-agent-ai-challenge
Assistant built for the Rasa Agent Challenge using CALM

# Navigation Voice Bot

- Aids in simple navigation between two locations, providing route details in English.

# Features

- Asks for the preferred language, this is done to make the bot multilingual, in assisting users with preferrable language
- Collects from and to destination
- Provides navigation from thr provided from and to locations
- Made the bot use ASR and TTS to communicate with the user with voice
